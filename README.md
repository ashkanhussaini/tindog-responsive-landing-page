# TinDog --- Responsive Landing Page

TinDog is a responsive landing-page project for a fictional app that
helps dog owners connect with other dog owners and their dogs.

This project was built as part of my web development learning journey
while studying **The Complete 2024 Web Development Bootcamp by
Dr. Angela Yu**.

## Project Overview

The page includes a hero section, feature highlights, testimonials,
press logos, pricing plans, and a call-to-action section.

## Built With

-   HTML5
-   CSS3
-   Bootstrap 5
-   Bootstrap Icons

## What I Practiced

-   Structuring a multi-section webpage with HTML
-   Styling page elements with CSS
-   Using Bootstrap components and layout utilities
-   Creating a responsive landing-page layout
-   Organizing project assets into folders

## Run Locally

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in your web browser.

No build step is required.
